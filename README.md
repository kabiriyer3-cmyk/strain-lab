# STRAIN LAB

Песочница разрушений по мотивам **THE FINALS**, собранная заново для браузера: заранее расколотые здания, структурный расчёт Strain, gradual destruction (шарниры и провисание), физика обломков, кучи щебня и взрывные волны. Играется с мыши и с телефона.

**Играть:** https://kabiriyer3-cmyk.github.io/strain-lab/

## Что нового во второй версии

- **Телефон и планшет.** Сенсорное управление: плавающий левый стик (до упора = бег), обзор правым пальцем, кнопки ОГОНЬ (держать = очередь, водить пальцем = целиться), ПРЫЖОК, ПОДРЫВ для C4, ЗИП у троса, тап по слоту оружия, панель с меню, видами, графом, слоумо, полётом и сбросом. На тач-устройствах по умолчанию низкая графика: меньше фрагментов (`fracScale 0.6`, тот же граф Strain), до 240 обломков, без постобработки. Полный экран и альбомная ориентация на Android, манифест для «добавить на экран».
- **Звук из реальных записей.** Вместо синтеза: взрывы, щебень, стекло, дерево, металл, скрип, выстрелы, шаги и интерфейс из CC0-библиотек (список ниже). Варианты со случайной высотой, стерео по положению, затухание и приглушение высоких с расстоянием, задержка звука для дальних взрывов, свёрточная «уличная» реверберация, лимит голосов. Синтез остался запасным вариантом, только если файлы не загрузились.
- **Графика.** Небо Preetham, запечённое в кубическую карту и освещение от неба (IBL), процедурные текстуры на каждом фрагменте (бетон с опалубкой, кирпич, доски, металл, плитка, полосатые блоки), спроецированные в исходной позе, поэтому текстура едет вместе с обломком. Копоть от взрывов, ударная волна, пятна на земле, разметка улицы, городские кварталы по краям. На высокой графике: MSAA, GTAO (тени в углах и под плитами), мягкий bloom, тени тянутся за камерой. Если FPS проседает, игра сама выключает AO и снижает разрешение.
- **Уровень.** Квартал перестроен: фасады смотрят на улицу, пять зданий (паркинг без стен, дом с лестницей на все этажи и крышу, башня, кирпичный дом, деревянное кафе), мост и ферма с джамботроном, тротуары, фонари, бетонные блоки, ящики, кэшаут. Четыре зиплайна по крышам, три лестницы-стремянки, три батута. Зиплайн обрывается, если рушится то, к чему он прикручен.

## Как устроено разрушение в THE FINALS

Коротко, по открытым источникам (список внизу):

- **Всё раскалывается заранее.** Здания собираются в Houdini (тулсет Building Creator) из модулей, каждый модуль заранее режется на фрагменты. В рантайме ничего не режется, только отсоединяется. Соседние выпуклые оболочки сливаются, чтобы коллизий было меньше.
- **Граф связей.** Фрагменты соединены связями, части, стоящие на земле, служат опорами. Связи генерирует инструмент прямо в уровне (connection tool), здания делятся на strain groups.
- **Strain.** Слой структурной целостности: граф рассчитывается как конструкция под собственным весом, решатель прямой разреженный (Холецкий). Связь рвётся, когда сочетание осевой силы, сдвига и изгиба выходит за порог в форме ромба (с небольшим случайным сдвигом, чтобы здания ломались неодинаково). Работа размазывается по кадрам, всё считается на сервере.
- **Физика.** Оторванные куски становятся твёрдыми телами (PhysX), бьют по окружению и ломаются дальше.
- **Сеть.** Состояние реплицируется снапшотами и дельтами, на GDC называли снижение примерно с 400 до 175 кбит/с.
- **PRIME TIME (12.0.0, 20.10.2026)** добавил между Strain и физикой третий слой, **gradual destruction**: после разрыва куски не падают сразу, а держатся на подвижных связях, поэтому полы встают рампой, коридоры скручиваются, комнаты провисают. Ещё в патче: подвесные конструкции на физических тросах, Blast Waves (стены вминаются, обломки разлетаются), растущие кучи обломков, скрип и пыль перед обрушением.

## Калибровка

Прочности игровые, а не СНиП: здание должно пережить одну ракету, но сложиться, когда опоры почти выбиты. Бетон: растяжение 2600, сжатие 6000, сдвиг 2200 кН/м²; кирпич держит сдвиг 950, дерево 620. Ненесущие элементы мягче несущих (подоконник 0.5, перегородка 0.05, парапет 0.3, стекло 0.01), чтобы они висели на каркасе, а не тянули нагрузку на себя.

Тесты (`npm test`, их же гоняет CI): модули не пересекаются, все сцены стоят в покое и на полной, и на мобильной нарезке, зиплайны не задевают здания и заканчиваются над крышей. Проверено и вручную: без опор первого этажа дом с лестницей складывается целиком.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, мышь | ход и обзор (стрелки, если мышь не захвачена) |
| ЛКМ / ПКМ или F | огонь / подрыв C4 |
| 1–8, колесо | оружие: RPG-7, кувалда, C4, граната, AKM, Charge'N'Slam, метеор, шар-таран |
| Space, Shift | прыжок (двойной), бег |
| E | зацепиться за зиплайн (едет туда, куда смотришь), ещё раз E или Space: отцепиться |
| W у лестницы | лезть, Space: спрыгнуть |
| V | полёт (Space и C: вверх и вниз) |
| B | вид: обычный, нагрузка Strain, фрагменты, узлы, группы |
| G | граф Strain: связи, опоры, шарниры |
| T, P | слоумо, пауза физики |
| R, M, H | сброс арены, звук, подсказка |

**С телефона:** левый палец ходит (до упора = бег), правый смотрит, ОГОНЬ держать для очереди и водить для прицела, ПРЫЖОК, ПОДРЫВ (с C4 в руках), ЗИП появляется у троса, джойстик вперёд у лестницы, оружие тапом по слоту, сверху меню, вид, граф, слоумо, полёт, сброс.

Параметры адреса: `?scene=district|lab|house`, `?quality=low|high`, `?touch=1|0` (принудительно включить или выключить сенсорное управление), `?adapt=0` (без автоснижения качества), `?worker=0` (Strain в основном потоке).

## Звуки

Все файлы CC0 (общественное достояние), закреплены на конкретных коммитах публичных зеркал, список в `src/game/sfx.js`:

- **Kenney** ([kenney.nl](https://kenney.nl)): Impact Sounds, Sci-fi Sounds, RPG Audio, Interface Sounds, через зеркало [Mcamento8/open-game-sfx-index](https://github.com/Mcamento8/open-game-sfx-index); там же **artisticdude**, [RPG Sound Pack](https://opengameart.org/content/rpg-sound-pack) (взмахи)
- **rubberduck**, [75 CC0 breaking / falling / hit sfx](https://opengameart.org/content/75-cc0-breaking-falling-hit-sfx) (щебень, стекло, дерево, металл), через [fighter-435/Break-the-Battle-Formation](https://github.com/fighter-435/Break-the-Battle-Formation)
- **unfa**, [Weapons_Handgun_Shot](https://freesound.org/people/unfa/sounds/565130/) и **Spring Spring**, [Mechanical Explosion](https://opengameart.org/content/mechanical-explosion), через [TP-Coltec-UFMG/2026-303-Asimov](https://github.com/TP-Coltec-UFMG/2026-303-Asimov)

`npm run build` скачивает их в `dist/sfx/` (около 150 файлов, кэш в `.sfx-cache/`) вместе с `CREDITS.txt`. Если папки нет (сборка без сети или `--no-sfx`), игра берёт те же файлы напрямую с GitHub. Ogg Vorbis играет в Chrome, Firefox, Edge и Safari 18.4+.

## Запуск локально

```bash
npm install
npm test         # тесты ядра: геометрия, Strain в покое, зиплайны, звуковой манифест
npm run build    # dist/: index.html + game.js (three.js и Rapier WASM внутри) + sfx/
```

`dist/index.html` открывается прямо с диска, сервер не нужен. Для разработки: `npm run dev` (http://localhost:5173). Флаги сборки: `--dev` без минификации, `--no-sfx` без скачивания звуков, `SFX_MIRROR=http://host/` для локального зеркала.

## Деплой

Workflow **Build & deploy** (`.github/workflows/pages.yml`) на каждый пуш в `main`: установка, тесты, сборка, артефакт `strain-lab-web` (zip с готовой игрой, работает офлайн) и выкладка на GitHub Pages.

## Структура

```
src/core/    геометрия и Strain: voronoi, structure, strain, sparse, strainRun, materials, scenes
src/sim/     рантайм разрушения: sim (слои, урон, шарниры, рампы), piles, strainService, strain.worker
src/render/  view (небо, IBL, чанки, обломки, копоть, улица), textures (процедурные), post (GTAO, bloom), fx
src/game/    player (ходьба, лестницы, зиплайны), weapons, hud, touch, audio, sfx (манифест звуков)
public/      страница, стили, манифест
tests/       тесты (node --test)
```
